# HydraKitMVVM

MVVM target của HydraKit.

## Mục Đích

ViewModel, HKViewState, ViewAction, binding helpers, effects và preview mock view model.

## Cài Đặt

Thêm product tương ứng vào target app hoặc module của bạn:

```swift
.product(name: "HydraKitMVVM", package: "IronBitCoreKit")
```

## Sử Dụng

```swift
import HydraKitMVVM
```

## Ghi Chú Migration

Hiện chưa có version public cũ của `HydraKitMVVM`. Khi có breaking change, hướng dẫn migration sẽ được cập nhật trong file này, `CHANGELOG.md` và DocC.
