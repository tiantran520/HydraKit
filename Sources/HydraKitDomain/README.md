# HydraKitDomain

Domain target của HydraKit.

## Mục Đích

Entity, value object, domain errors, validation errors và use case abstractions.

## Cài Đặt

Thêm product tương ứng vào target app hoặc module của bạn:

```swift
.product(name: "HydraKitDomain", package: "HydraKit")
```

## Sử Dụng

```swift
import HydraKitDomain
```

## Ghi Chú Migration

Hiện chưa có version public cũ của `HydraKitDomain`. Khi có breaking change, hướng dẫn migration sẽ được cập nhật trong file này, `CHANGELOG.md` và DocC.
