# IronBitCoreKitDev

Dev Tools target của IronBitCoreKit.

## Mục Đích

Debug-only dev menu, environment switcher, mock data provider và preview container.

## Cài Đặt

Thêm product tương ứng vào target app hoặc module của bạn:

```swift
.product(name: "IronBitCoreKitDev", package: "IronBitCoreKit")
```

## Sử Dụng

```swift
import IronBitCoreKitDev
```

## Ghi Chú Migration

Hiện chưa có version public cũ của `IronBitCoreKitDev`. Khi có breaking change, hướng dẫn migration sẽ được cập nhật trong file này, `CHANGELOG.md` và DocC.
