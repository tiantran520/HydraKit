# IronBitCoreKitUI

UI target của IronBitCoreKit.

## Mục Đích

Design tokens, theme, SwiftUI components, state views, layout, forms, media, animation, accessibility, localization và preview helpers.

## Cài Đặt

Thêm product tương ứng vào target app hoặc module của bạn:

```swift
.product(name: "IronBitCoreKitUI", package: "IronBitCoreKit")
```

## Sử Dụng

```swift
import IronBitCoreKitUI
```

## Ghi Chú Migration

Hiện chưa có version public cũ của `IronBitCoreKitUI`. Khi có breaking change, hướng dẫn migration sẽ được cập nhật trong file này, `CHANGELOG.md` và DocC.
