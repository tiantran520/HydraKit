# HydraKitNetwork

Network target của HydraKit.

## Mục Đích

Endpoint, request builder, URLSession client, retry, interceptor, decoding, cache, reachability, security và mock client.

## Cài Đặt

Thêm product tương ứng vào target app hoặc module của bạn:

```swift
.product(name: "HydraKitNetwork", package: "HydraKit")
```

## Sử Dụng

```swift
import HydraKitNetwork
```

## Ghi Chú Migration

Hiện chưa có version public cũ của `HydraKitNetwork`. Khi có breaking change, hướng dẫn migration sẽ được cập nhật trong file này, `CHANGELOG.md` và DocC.
