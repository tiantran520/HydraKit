# IronBitCoreKitAnalytics

Analytics target của IronBitCoreKit.

## Mục Đích

Analytics provider/service, event/screen tracking, crash reporting, performance, remote config, A/B testing và feature flags.

## Cài Đặt

Thêm product tương ứng vào target app hoặc module của bạn:

```swift
.product(name: "IronBitCoreKitAnalytics", package: "IronBitCoreKit")
```

## Sử Dụng

```swift
import IronBitCoreKitAnalytics
```

## Ghi Chú Migration

Hiện chưa có version public cũ của `IronBitCoreKitAnalytics`. Khi có breaking change, hướng dẫn migration sẽ được cập nhật trong file này, `CHANGELOG.md` và DocC.
