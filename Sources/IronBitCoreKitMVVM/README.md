# IronBitCoreKitMVVM

MVVM target của IronBitCoreKit.

## Mục Đích

ViewModel, ViewState, ViewAction, binding helpers, effects và preview mock view model.

## Cài Đặt

Thêm product tương ứng vào target app hoặc module của bạn:

```swift
.product(name: "IronBitCoreKitMVVM", package: "IronBitCoreKit")
```

## Sử Dụng

```swift
import IronBitCoreKitMVVM
```

## Ghi Chú Migration

Hiện chưa có version public cũ của `IronBitCoreKitMVVM`. Khi có breaking change, hướng dẫn migration sẽ được cập nhật trong file này, `CHANGELOG.md` và DocC.
