# IronBitCoreKitRepository

Repository target của IronBitCoreKit.

## Mục Đích

Readable/writable/streamable repositories, DTO mapper, network/local/hybrid strategies và mock repository.

## Cài Đặt

Thêm product tương ứng vào target app hoặc module của bạn:

```swift
.product(name: "IronBitCoreKitRepository", package: "IronBitCoreKit")
```

## Sử Dụng

```swift
import IronBitCoreKitRepository
```

## Ghi Chú Migration

Hiện chưa có version public cũ của `IronBitCoreKitRepository`. Khi có breaking change, hướng dẫn migration sẽ được cập nhật trong file này, `CHANGELOG.md` và DocC.
