# IronBitCoreKitSecurity

Security target của IronBitCoreKit.

## Mục Đích

Auth, OAuth2/PKCE, biometric auth, session management, auto logout và crypto helpers.

## Cài Đặt

Thêm product tương ứng vào target app hoặc module của bạn:

```swift
.product(name: "IronBitCoreKitSecurity", package: "IronBitCoreKit")
```

## Sử Dụng

```swift
import IronBitCoreKitSecurity
```

## Ghi Chú Migration

Hiện chưa có version public cũ của `IronBitCoreKitSecurity`. Khi có breaking change, hướng dẫn migration sẽ được cập nhật trong file này, `CHANGELOG.md` và DocC.
