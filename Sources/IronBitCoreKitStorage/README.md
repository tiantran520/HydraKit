# IronBitCoreKitStorage

Storage target của IronBitCoreKit.

## Mục Đích

Storage protocols, UserDefaults, Keychain, file storage, SwiftData, CoreData và cache.

## Cài Đặt

Thêm product tương ứng vào target app hoặc module của bạn:

```swift
.product(name: "IronBitCoreKitStorage", package: "IronBitCoreKit")
```

## Sử Dụng

```swift
import IronBitCoreKitStorage
```

## Ghi Chú Migration

Hiện chưa có version public cũ của `IronBitCoreKitStorage`. Khi có breaking change, hướng dẫn migration sẽ được cập nhật trong file này, `CHANGELOG.md` và DocC.
