# IronBitCoreKitDomain

Domain target của IronBitCoreKit.

## Mục Đích

Entity, value object, domain errors, validation errors và use case abstractions.

## Cài Đặt

Thêm product tương ứng vào target app hoặc module của bạn:

```swift
.product(name: "IronBitCoreKitDomain", package: "IronBitCoreKit")
```

## Sử Dụng

```swift
import IronBitCoreKitDomain
```

## Ghi Chú Migration

Hiện chưa có version public cũ của `IronBitCoreKitDomain`. Khi có breaking change, hướng dẫn migration sẽ được cập nhật trong file này, `CHANGELOG.md` và DocC.
