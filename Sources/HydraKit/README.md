# HydraKit

Core utilities target của HydraKit.

## Mục Đích

Extensions, logging, error handling, dependency injection, concurrency và utilities nền tảng.

## Cài Đặt

Thêm product tương ứng vào target app hoặc module của bạn:

```swift
.product(name: "HydraKit", package: "IronBitCoreKit")
```

## Sử Dụng

```swift
import HydraKit
```

## Ghi Chú Migration

Hiện chưa có version public cũ của `HydraKit`. Khi có breaking change, hướng dẫn migration sẽ được cập nhật trong file này, `CHANGELOG.md` và DocC.
