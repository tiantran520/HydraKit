# HydraKitNavigation

Navigation target của HydraKit.

## Mục Đích

Coordinator, route abstraction, router, deep link, tab, sheet và flow coordinators.

## Cài Đặt

Thêm product tương ứng vào target app hoặc module của bạn:

```swift
.product(name: "HydraKitNavigation", package: "IronBitCoreKit")
```

## Sử Dụng

```swift
import HydraKitNavigation
```

## Ghi Chú Migration

Hiện chưa có version public cũ của `HydraKitNavigation`. Khi có breaking change, hướng dẫn migration sẽ được cập nhật trong file này, `CHANGELOG.md` và DocC.
