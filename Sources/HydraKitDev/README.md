# HydraKitDev

Dev Tools target của HydraKit.

## Mục Đích

Debug-only dev menu, environment switcher, mock data provider và preview container.

## Cài Đặt

Thêm product tương ứng vào target app hoặc module của bạn:

```swift
.product(name: "HydraKitDev", package: "HydraKit")
```

## Sử Dụng

```swift
import HydraKitDev
```

## Ghi Chú Migration

Hiện chưa có version public cũ của `HydraKitDev`. Khi có breaking change, hướng dẫn migration sẽ được cập nhật trong file này, `CHANGELOG.md` và DocC.
