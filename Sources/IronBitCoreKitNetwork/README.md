# IronBitCoreKitNetwork

Network target của IronBitCoreKit.

## Mục Đích

Endpoint, request builder, URLSession client, retry, interceptor, decoding, cache, reachability, security và mock client.

## Cài Đặt

Thêm product tương ứng vào target app hoặc module của bạn:

```swift
.product(name: "IronBitCoreKitNetwork", package: "IronBitCoreKit")
```

## Sử Dụng

```swift
import IronBitCoreKitNetwork
```

## Ghi Chú Migration

Hiện chưa có version public cũ của `IronBitCoreKitNetwork`. Khi có breaking change, hướng dẫn migration sẽ được cập nhật trong file này, `CHANGELOG.md` và DocC.
