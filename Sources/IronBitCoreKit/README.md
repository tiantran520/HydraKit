# IronBitCoreKit

Core utilities target của IronBitCoreKit.

## Mục Đích

Extensions, logging, error handling, dependency injection, concurrency và utilities nền tảng.

## Cài Đặt

Thêm product tương ứng vào target app hoặc module của bạn:

```swift
.product(name: "IronBitCoreKit", package: "IronBitCoreKit")
```

## Sử Dụng

```swift
import IronBitCoreKit
```

## Ghi Chú Migration

Hiện chưa có version public cũ của `IronBitCoreKit`. Khi có breaking change, hướng dẫn migration sẽ được cập nhật trong file này, `CHANGELOG.md` và DocC.
