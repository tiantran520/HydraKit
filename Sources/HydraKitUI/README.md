# HydraKitUI

UI target của HydraKit.

## Mục Đích

Design tokens, theme, SwiftUI components, state views, layout, forms, media, animation, accessibility, localization và preview helpers.

## Cài Đặt

Thêm product tương ứng vào target app hoặc module của bạn:

```swift
.product(name: "HydraKitUI", package: "HydraKit")
```

## Sử Dụng

```swift
import HydraKitUI
```

## Ghi Chú Migration

Hiện chưa có version public cũ của `HydraKitUI`. Khi có breaking change, hướng dẫn migration sẽ được cập nhật trong file này, `CHANGELOG.md` và DocC.
